# Oluwatobiloba Olufowobi — Portfolio Website

This is a static website for GitHub Pages.

## Publish
1. Create a **public** repository named `olufowobijosh.github.io` under the GitHub account `OlufowobiJosh` (GitHub repository names are case-insensitive).
2. Choose **Add file → Upload files** in the repository.
3. Upload `index.html` and `style.css` directly into the repository root (not inside a subfolder).
4. Commit changes.
5. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
6. Open https://olufowobijosh.github.io after GitHub finishes publishing.
